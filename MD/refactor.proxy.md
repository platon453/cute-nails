## Задача: Рефакторинг проксирования для Telegram-бота

## Контекст:

Текущая реализация VPN/Proxy через контейнер xray и жестко заданный config.json слишком сложна в поддержке. Нам необходимо отказаться от ручного парсинга UUID и SNI из ссылок подписки (формат https://easybridgy.space:8443/sub/...) и перейти на использование v2rayA — клиента с удобным Web-интерфейсом.

Важное требование безопасности: Так как у нас нет домена и SSL-сертификата, Web-интерфейс v2rayA не должен торчать наружу в открытый интернет. Доступ к админке будет осуществляться исключительно через SSH-туннель (проброс портов).

## Что нужно сделать:

1. **Обновить docker-compose.yml**

- Удали сервис xray и связанные с ним вольюмы для конфигов. Замени его на сервис v2raya. Также убедись, что сервис bot теперь зависит от v2raya, а не от xray.

- Используй следующий манифест (обрати особое внимание на привязку порта 2017 строго к 127.0.0.1):

```yaml
v2raya:
    image: mzz2017/v2raya:latest
    container_name: cute_nails_v2raya
    restart: unless-stopped
    ports:
      - "127.0.0.1:2017:2017" # Панель закрыта от интернета, доступ только через SSH-туннель локально
    volumes:
      - ./v2raya_data:/etc/v2raya
```

2. **Обновить инициализацию бота (Python / aiogram):**

- Так как v2rayA автоматически поднимает HTTP-прокси на порту 20171 для всех сервисов в Docker-сети, бот должен направлять свои запросы через этот порт, обращаясь к контейнеру по его имени (v2raya).

- Внеси изменения в файл, где инициализируется экземпляр Bot. Добавь использование AiohttpSession с параметром proxy:

```python
from aiogram import Bot
from aiogram.client.session.aiohttp import AiohttpSession

# ВАЖНО: Добавить сессию с прокси v2raya
session = AiohttpSession(proxy="http://v2raya:20171")

# Передать сессию при инициализации бота
bot = Bot(
    token=config.BOT_TOKEN, # Твой способ получения токена
    session=session,
    # остальные параметры...
)
```

Ожидаемый результат:

1. Полностью удален xray-config.json из проекта.

2. В docker-compose.yml интегрирован v2raya, порт 2017 проброшен ТОЛЬКО на 127.0.0.1 для защиты от внешнего доступа.

3. Код бота обновлен: трафик к API Telegram маршрутизируется через http://v2raya:20171.
